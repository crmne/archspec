## Technical check (live site, 2026-11-13)

The site already runs `bin/audit-seo.rb` after every build, and it shows: every sitemap URL answers 200 with one h1, a self-canonical, descriptions of 120 to 158 characters, JSON-LD that parses, a PNG social card that answers 200, and no broken internal links or orphans. http and www redirect to https with 301. CLS 0 to 0.036, LCP under 0.5 s on a phone, pages about 180 KB, no sideways scroll at 390 px.

What this pass did: `seo.title`s for Modular Monolith, Hexagonal, Event Driven, and Ruby Conventions ("... architecture preset" / "... preset", like Clean, CQRS, Layered, and Rails), and for the Components, Constants, Dependencies, and Protocols rules ("Component structure rules", "Constant reference rules", "Component dependency rules", "Protocol implementation rules", like the other rule pages). Sidebar titles are unchanged.

Proposals:

- `/next/` is indexable with self-canonicals and its sitemap is in `robots.txt`, so Google sees two copies of every page (78 here, the most of the three sites). A theme change in crmne/jekyll-vitepress-theme: `noindex` the `/next/` build or canonicalize it to the stable page.
- These changes are on `master`, which the docs workflow publishes at `/next/`; they reach `/` with the next release tag.
